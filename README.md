# KIZMU Site

Static pages for KIZMU App Store metadata.

## Pages

- `/privacy/`
- `/terms/`
- `/support/`

## GitHub Pages

Create a public repository such as `kizmu-site`, put these files at the repository root, then enable GitHub Pages from the `main` branch root.

Expected URLs:

- `https://<github-user>.github.io/kizmu-site/privacy/`
- `https://<github-user>.github.io/kizmu-site/terms/`
- `https://<github-user>.github.io/kizmu-site/support/`
